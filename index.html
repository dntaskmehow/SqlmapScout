Reconnaissance pipeline

Move from surface
to signal.

Every stage is bounded, inspectable, and designed to leave static assets and unrelated hosts behind.

01 / SCOPE

Set boundaries

Define the origin URL, crawl depth, page limit, concurrency, timeout, and output destination.

02 / DETECT

Extract signals

Record query parameters, dynamic routes, GET forms, and POST form fields without broad exploitation.

03 / EXPORT

Prepare targets

Export links only or append generated SQLMap commands in human-readable text or structured JSON.

Operational view

A terminal built for
decisions.

Live telemetry turns crawl behavior into visible progress instead of hiding the process behind a silent batch job.

Scope engine

Stay inside the origin.

Reject cross-host, unsupported-scheme, and static asset paths before they enter the crawl queue.

Export modes

Keep the output usable.

Choose URLs only or pair each finding with its method, parameters, reason, status, and generated command.

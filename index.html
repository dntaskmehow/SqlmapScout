Recon workflow

From web surface to clean targets.

A bounded crawl that separates actionable endpoints from static assets and unrelated noise.

Start from an origin URL, then set crawl depth, page limits, concurrency, and request timeout.

Capabilities

Built for a focused TUI workflow.

Runtime controls and live telemetry keep the crawl visible without turning reconnaissance into a noisy data dump.

Rich terminal interface

See the crawl as it happens.

A live layout reports queue depth, crawl progress, HTTP responses, filtered noise, and verified signal links.

$ python sqlmap_scout.py -u https://example.com
› CRAWLED 48/80   SIGNAL 7   NOISE 41
› Exported (with-commands) → targets.txt
Scope control

Stay on target.

HTTP and HTTPS crawling remains bound to the starting host while static assets are excluded.

Output modes

Keep or extend.

Export signal URLs only, or pair each target with a generated sqlmap command in TXT or JSON.

Get started

Run a bounded scout.

Install the Rich terminal dependency, then point SQLMap Scout at a system you are authorized to test.

pip install rich && python sqlmap_scout.py -u https://example.com --max-pages 80 --auto-export
